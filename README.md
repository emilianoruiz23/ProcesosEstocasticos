**Procesos Estocásticos**

Recopilación estructurada de notas, demostraciones teóricas y resolución de problemas correspondientes a la materia de Procesos Estocásticos. Este repositorio funciona como una base de conocimiento para el modelado de sistemas que evolucionan aleatoriamente en el tiempo.

**Temas Principales**
*   **Fundamentos de Probabilidad:** Revisión de espacios de probabilidad, variables aleatorias y esperanza matemática.
*   **Cadenas de Markov:** Análisis de estados, matrices de transición, clasificación de estados y distribuciones estacionarias.
*   **Procesos de Poisson:** Tiempos de llegada, conteo de eventos y propiedades de incrementos independientes.
*   **Aplicaciones y Modelado:** Uso de los procesos estocásticos en teoría de la ruina, predicción y análisis de riesgo.
